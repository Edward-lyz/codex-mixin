# macOS 资源规范

继承上级规范。这里管理 Agent/provider 标识与 NASA 装饰资源，不包含业务逻辑。

- 优先复用现有品牌资源和 manifest；资源 ID 与 core/CLI 的固定 ID 一致。
- 新资源记录来源、许可证及商标说明；禁止复制不明来源素材或重新绘制品牌标记冒充官方版本。
- 图片尺寸/体积按实际显示用途控制，SVG 保持可安全解析，不含脚本、外部引用或嵌入凭据。
- macOS 为 Windows/README 派生资源的来源之一；修改同步消费者，不手改忽略的生成目录。
- 验证 manifest 路径、文件格式与浅深色展示；Agent/provider 资源执行相应 logo/support 测试，整体资源变更验证 App 构建。
