# Windows 原生窗口规范

继承上级规范。这里是 Flutter Win32 Host 的进程、窗口、资源与消息生命周期。

- 只处理嵌入、消息、窗口行为和资源，不启动业务网关或读写用户业务配置。
- HWND、COM、消息回调和窗口对象所有权明确，失败保留系统原因，销毁收敛资源。
- 跨 Flutter/原生边界不阻塞消息线程；按已有多窗口/托盘约定，不另写 UI 状态机。
- 保持 UTF-16 路径、DPI、缩放、焦点和系统主题语义；更新资源 ID 同步 RC/header/manifest。
- 在 Windows 验证 release 构建，并实际检查窗口打开/隐藏/关闭、多窗口、缩放和键盘焦点；只在 macOS 阅读代码不能证明行为通过。
