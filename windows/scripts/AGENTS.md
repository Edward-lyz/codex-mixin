# Windows 安装与打包规范

继承上级规范。这里是 PowerShell/NSIS 打包、安装、卸载与已定义插件 patch 的入口。

- 错误立即失败并保留阶段/退出码；PowerShell 外部工具调用检查 `$LASTEXITCODE`，不因命令返回对象就认为成功。
- 路径含空格/中文时仍正确，参数用数组；下载、归档解压与清理校验目标，不能清空未确认的用户目录。
- 资源通过 generate-windows-assets 从 macOS 来源生成；patch 必须匹配已知插件版本/上下文，不匹配就停止。
- 安装/卸载保留用户配置与凭据，PATH 修改去重并只撤销本项目项；沿用真实安装范围与 ACL 语义。
- NSIS 升级依据已有卸载注册信息定位旧安装，不能猜测目录删除；签名密钥不写入文件或日志。
- Windows 实机验证全新安装、升级、卸载、重复执行与空格路径；打包运行 package-windows.ps1。未执行这些流程不得宣称安装器已验证。
