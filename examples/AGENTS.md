# 示例与性能探针规范

继承根规范。这里是通过 Cargo example 运行的可复现示例，不是第二套产品实现。

- 复用真实库 API，不复制协议/请求栈；参数、必要环境和输出含义写清楚。
- 探针只测明确目标，说明样本、时间单位、输入与环境；单次测量不能宣称普遍性能提升。
- 不内嵌凭据或私有 endpoint，不默认写入用户配置；真实网络/费用行为必须可辨识。
- 计时使用单调时钟，循环/并发/内存有界，不用无限运行作为默认行为。
- 执行 `cargo check --locked --examples`；现有 `perf_probe` 使用源码定义的固定输入，没有参数解析，运行命令为 `cargo run --locked --example perf_probe`，报告实际环境与结果。
