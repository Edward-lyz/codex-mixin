# ECH 与 DNS 规范

继承上级规范。本目录与 `../ech.rs` 实现官方目标的 opt-in ECH transport，`dns.rs` 解析 DNS HTTPS/ECH 数据。

- 只处理已定义的官方目标，不扩大成任意代理；TLS 证书验证与服务名保持真实目标。
- DNS 二进制按长度、压缩指针、记录类型和 ECH 配置边界校验，截断/循环/非法值明确失败。
- 缓存遵守 TTL、容量和刷新串行语义；不要为每个请求重复 DNS 查询。
- ECH 不可用时保留现有显式禁用/直连降级及诊断，不能引入无日志的成功默认值。
- 超时、取消与连接资源有界，不输出认证或敏感 payload。
- 运行 ECH 相关 Rust 测试，结合 `tests/fixtures/ech/` 验证真实格式、损坏记录、过期和降级；实时网络验证另报告环境与结果。
