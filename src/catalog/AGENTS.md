# 模型目录规范

继承上级规范。本目录与 `../catalog.rs` 负责来源加载、目录生成、模板、托管目录与缓存。

- official、自定义和 Fusion 模型来源与 ID 明确；同名模型不得通过展示名称合并。
- 目录由 provider 元数据/能力生成，不参与请求执行；能力未知不得宣称支持。
- 缓存键覆盖影响目录的配置/能力变化；变更后正确失效，避免 GUI 与网关看到不同模型集合。
- 模板和托管目录更新保留客户端要求与非托管内容；读取损坏缓存要报告原因或使用已定义的显式刷新流程。
- 元数据加载/发现是目录来源能力，不能借此加入网关路由编排或 UI 逻辑。
- 验证来源合并、稳定 slug、能力失效、禁用 provider 与客户端上下文，运行 catalog 测试、`cargo test --locked --test official_client_contexts` 和根级门禁。
