# Agent 版本与升级规范

继承上级规范。这里检测真实安装来源与版本，并按来源执行升级，不猜测安装包。

- 本地检测和查询最新版本分开；查询失败保留 `latest = None` 与原因，不能显示“已是最新”。
- 仅有经源码/官方入口确认的安装来源才提供升级。未知来源明确返回不可用，不尝试任意 shell 命令。
- 进程内与跨进程升级均保持单 Agent 串行；缓存仅保留在进程内，新的 CLI 调用重新检测机器状态。
- npm、Homebrew、桌面安装等 OS 差异由 platform 表达；不向 GUI 暴露包管理细节让其重新实现。
- 保留固定 Agent ID；动态 WSL/profile 发现按自己的入口处理，不伪造固定列表条目。
- 验证未知版本、缺包管理器、来源冲突、重复升级与失败锁释放，运行 `cargo test --locked agent_versions` 和根级门禁。
