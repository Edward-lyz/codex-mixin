# 图片处理规范

继承上级规范。`normalize` 处理请求内图片规范化/压缩，`generation` 管理 imagegen 路由标记与辅助 provider。

- 相同输入与配置产生稳定规范化结果，维持多轮缓存前缀；413 fallback 只在既有明确条件触发。
- 图片解码限制尺寸、像素、格式和输出体积；CPU 密集处理放在 blocking worker，不阻塞转发 runtime。
- 数据 URL、base64 和 marker 在边界校验；非法图片清晰失败，不生成空图片替代。
- 生成路由绑定明确 provider/会话与生命周期，不泄漏标记或跨请求串用；不在此承担 GUI 文件选择。
- 保留协议多模态次序与语义，不为压缩删除用户内容。
- 运行 images 相关 Rust 测试，验证稳定输出、过大/损坏图片、413 重试与路由隔离；前缀变化运行缓存 E2E。
