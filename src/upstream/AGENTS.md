# 上游传输规范

继承上级规范。这里准备与发送 provider/官方请求，管理认证运行时、传输压缩和协议相关重试。

- 调用者传入准确目标和 headers；这里不解析业务路由，不持有入站服务状态，不调用网关或多模型编排。
- 复用连接池与认证运行时，保持模型级 endpoint、Baidu/DUCX/AWS 语义和官方 header 隔离。
- body 序列化后再签名；重试需考虑已经发送的流事件与副作用，不能无条件重放请求。
- ECH、压缩、413 等既有降级均保留明确条件、次数上限和诊断；不得新增静默直连或协议猜测。
- 流式读取有界，错误带上目标/阶段但脱敏；连接、取消与子进程生命周期明确。
- 用 E2E 验证官方/自定义 header、认证与流式转发；鉴权修改补 `client-auth` 门禁。
