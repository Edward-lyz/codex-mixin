# Web Search 能力规范

继承上级规范。这里处理搜索能力状态、最小探测、缓存与类型，不拥有 UI 或网关编排。

- `probe` 执行真实协议探测，`capabilities` 管理结果，`storage` 保存缓存，`types` 定义语义。
- 区分支持、不支持、未知与失败；端点/认证/模型身份变化后旧结论失效。
- 搜索工具 schema 和 provider 协议保持一致，不把普通文本答案当成工具支持证据。
- 限制探测并发、超时和费用；网络操作在存储锁外，不能每个请求重复探测。
- 保留无关缓存记录，写入原子且私有；日志不包含凭据、搜索敏感内容或原始请求。
- 运行 `cargo test --locked web_search` 与相关缓存测试，覆盖协议差异、失败、身份变化及损坏存储，再执行根级门禁。
