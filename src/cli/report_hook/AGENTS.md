# 使用上报规范

继承上级规范。这里拥有 Mixin 的上报入口及既有队列，不通过 UI 私有逻辑发送。

- `installation` 管理托管 hook，`queue` 管理持久化/去重，`transport` 管理发送；新增可复用规则不得继续绑定 CLI 呈现。
- 队列版本、事件实例 ID 和已投递状态保持明确；先可靠落盘再发送，失败保留可重试状态。
- 重试次数、并发与日志体积有界；发送成功才标记投递，不以加入队列冒充已送达。
- 队列锁不跨网络请求；原子文件与权限沿用已有能力，不损坏用户原有 hook。
- 上报 token、认证和代码内容不得进入普通日志；只发送已有明确 contract 允许的字段，不增加隐式采集。
- 验证重复事件、损坏队列、发送失败、重试及恢复；运行 `cargo test --locked report_hook` 和根级门禁。
