# CLI 测试规范

继承上级规范。这里验证核心命令行为、输入输出和客户端接入契约。

- 测试驱动真实 CLI/生产 helper；JSON 成功结果、stderr 错误 envelope 与退出码分别断言。
- 使用临时 HOME、状态和配置目录，不能覆盖开发者真实 Codex/Agent 配置。
- 对写操作验证持久化结果与非托管字段保留；失败覆盖提交前后阶段，不只匹配提示语。
- 子进程和环境变量修改需隔离；本地服务器使用随机可用端口，并在结束时收敛资源。
- 新能力覆盖 `--no-tui`，不能依赖真实终端。修 bug 先观察新增测试失败，再观察修复通过。
- 执行 `cargo test --locked --bin codex-mixin`；契约跨层时补运行对应 `tests/` 用例和根级门禁。
