# Provider 能力探测规范

继承上级规范。`types` 定义状态与身份，`probe` 发起探测，`storage` 保存缓存；入口负责组合。

- 缓存以真实 ProviderIdentity 匹配配置，端点、认证或模型身份变化不沿用旧结论。
- 区分未知、支持、不支持与探测错误；错误保留上下文，不被写成永久“不支持”。
- 探测使用真实协议与最小请求，遵守已有并发/超时常量；不在每次转发时重新探测。
- 存储更新保持锁和原子写入；探测网络在锁外，失败不覆盖有效的无关记录。
- 进度 callback 不带 UI 依赖，能力信息供 CLI/目录消费，不参与网关编排。
- 运行 `cargo test --locked --test provider_probe_cache` 及 capabilities 相关测试，覆盖身份失效、部分失败、缓存损坏与并发上限。
