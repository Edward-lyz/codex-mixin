# 上游认证规范

继承上级规范。这里只处理凭据生成/捕获、AWS SigV4、DUCX 运行时与外部认证头。

- 签名依据最终 URL、方法、body 和 headers；修改请求后重新签名，不复用失效签名。
- 认证刷新/捕获与普通请求生命周期分开，保持超时、取消和进程清理；不将捕获代理变成通用网关。
- 只向目标 provider 发送其认证，避免官方与自定义请求间 header、cookie 或 token 串用。
- 环境来源凭据缺失时清晰失败；不尝试无认证请求冒充成功，不输出捕获 body 或签名材料。
- 外部输入在边界校验；平台进程和路径差异交给 platform。
- 验证签名请求一致性、认证隔离、缺凭据及刷新失败，鉴权修改同时执行 `client-auth` 的 Clippy/测试门禁。
