# 配置与存储规范

继承上级规范。本目录与 `../config.rs` 共同拥有配置模型、迁移、加密、锁和持久化。

- 配置版本及 provider 类型使用已有常量/类型；迁移处理已知历史格式，对未知版本或损坏数据明确失败。
- 修改通过既有 mutate/save API，保持锁、原子替换和当前用户私有权限；不能分散直写主配置。
- 锁内只做读取、校验与提交；网络发现、能力探测、目录同步在锁外执行。
- 备份/导入校验结构及版本，保留用户确认的覆盖语义。Base64 不是加密，不在日志输出解密配置。
- 存储不渲染 UI、不发业务请求、不决定 GUI 生命周期；路径与权限的 OS 差异交给 platform。
- 用 E2E 验证迁移与备份往返，并运行根级门禁。
