# 文档规范

继承根规范。文档说明真实能力、架构和使用步骤，不能把计划描述成已实现。

- 代码/CLI contract 是事实依据；架构与目录规范有差异时先查证并注明现状，不凭文档推动无关重构。
- 命令注明工作目录、前提、失败语义和预期结果；不写不存在的命令、参数或测试门禁。
- 设计/研究文档标注范围与状态，区分事实、推断和建议；协议结论链接可核验来源。
- API key、个人路径和内部 endpoint 用明确占位值，截图与示例不包含敏感数据。
- 本地 Markdown 链接相对当前文档解析；架构边界变更同步 `architecture.md` 与对应 AGENTS，不重复维护冲突版本。
- 截图来自真实界面并脱敏；品牌派生资源保留来源，不冒充官方矢量重建。资源子目录继承本文件。
- 文档修改检查链接/命令存在性和 `git diff --check`；规范变更检查继承关系与架构门禁，明确没有执行的运行时检查。

阅读规范从根 `AGENTS.md` 进入：Rust 用例见 `src/application/`，CLI 见 `src/cli/`，请求面见 `src/server/`、`src/gateway/`、`src/upstream/`；外壳见 `macos/`、`windows/`、`tui/`。各目录仅补充本层规则，公共要求继承父级。
