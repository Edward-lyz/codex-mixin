# README Agent SVG assets

The README reuses colored SVG logos from `macos/assets/agents` directly.
Monochrome logos in this directory are derived from the same assets, with
`currentColor` replaced by fixed light/dark colors for standalone SVG images.

Crush, ZCode, Hanako, AtomCode, Alma, and Cindy are supplied as PNG logos.
Their SVG files embed the original PNG bytes without tracing or redesigning
the brand mark. These are SVG containers, not vector reconstructions.

See `../../../macos/assets/agents/ATTRIBUTION.md` for sources and ownership.
