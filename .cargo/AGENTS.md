# Cargo 构建配置规范

继承根规范。这里只放已有跨平台构建所需配置，不放个人机器设置。

- target rustflags 必须有具体硬件/ABI/构建问题依据；保留 Windows 主线程 stack 现有语义及说明。
- 不把绝对个人路径、内部代理、私有 registry 凭据或本机编译器配置提交到仓库。
- 不为绕过 lint/架构门禁修改全局编译选项，不以清理全部缓存作为常规构建步骤。
- target 配置变更验证对应平台构建与 CI，通用配置同时检查默认与 `client-auth` feature。
- 文档单独修改执行差异/引用检查即可；未实际构建的 target 明确报告。
